# Code of Conduct

## Our Pledge

We are committed to providing a welcoming and inclusive environment for everyone.

## Expected Behavior

- Be respectful.
- Be constructive.
- Help others learn.
- Respect different viewpoints.

## Unacceptable Behavior

- Harassment
- Personal attacks
- Hate speech
- Spam
- Discrimination

## Enforcement

Project maintainers may remove comments, commits, issues, or pull requests that violate this Code of Conduct.

## Contact

For questions, open an issue or contact the repository owner.
